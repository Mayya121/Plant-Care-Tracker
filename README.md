# Plant Care Tracker

##  Overview

Plant Care Tracker is an optimization-based project designed to support the management of indoor plants. It helps users select suitable locations for their plants based on lighting requirements and organize weekly care activities.

## Objectives

* Improve indoor plant placement
* Reduce plant neglect
* Organize weekly care schedules
* Support better plant-care decisions

## Key Features

* Plant registration and maintenance tracking
* Placement recommendations based on light requirements
* Weekly care-task scheduling
* Optimized allocation of plants to suitable indoor locations

##  Approach

The project uses Binary Linear Programming (BLP) to assign plants to appropriate locations and schedule their weekly care activities while considering plant requirements and available resources.

## Dataset

The system uses the Indoor Plant Health & Growth Dataset from Kaggle to support the optimization model.

## Methodologies and Tools

* Operations Research
* Binary Linear Programming
* Excel Solver
* Kaggle Dataset
